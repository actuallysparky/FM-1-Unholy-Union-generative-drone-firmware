# Contributing to UnholyUnion

Thanks for helping tend the choir. Report UnholyUnion bugs and feature ideas in [this repository's issues](https://github.com/actuallysparky/FM-1-Unholy-Union-generative-drone-firmware/issues). For stock Felucca behavior, use its upstream project instead.

Include your firmware version from ABOUT, the steps to reproduce the issue, what you expected and what happened. For editor or installer problems, include the browser/OS and a redacted event log. Keep private backups and identifying information out of reports.

Run the relevant tests in BUILDING.md before sending a pull request. Preserve engine and modulation IDs, project compatibility, flash partitions, source credits and licenses. Golden sound changes need a deliberate review. Hardware trials are separate from automated checks.
